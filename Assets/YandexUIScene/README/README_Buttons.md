# 🎮 游戏操作与按键说明 (README_Buttons)

本文档用于介绍在游戏各个状态下，手柄、键盘和鼠标的对应操作规则。

---

## 1. 首页 / 待机状态 (Idle)
* **目的**：开始游戏并进入下一步。
* **可用操作**：
  * **确认键**：键盘 `Space` (空格) / `Enter` (回车)，手柄 `A 键 / Cross 键 (buttonSouth)`。
  * **作用**：当开启了“确认键开始游戏”（`enableConfirmToStart = true`）时，按下确认键切换至【语言选择】页面。
  * **自动联网恢复机制**：每次通过结算倒计时结束、手动按返回键或中途点击 QUIT 退出返回首页时，系统会自动将 `PlayerPrefs` 中的 `GameMode` 重置为 `ONLINE`，并强制 `YandexWebSocketClient` 重新连接网络，确保首页始终处于联网状态。
  * **附加功能：游戏模式与场景切换选择菜单**：
    * **呼出菜单**：在**游戏任何阶段/状态下**，连续按 **5 次**“菜单键”（键盘 `Escape`，手柄 `Start 键`）即可呼出模式/场景切换界面。
    * **游戏自动暂停**：打开切换界面后，游戏会**自动暂停**（`Time.timeScale` 设为 `0f`），关闭菜单时将自动恢复至打开前的 `Time.timeScale`，防止干扰其他正常暂停。
    * **菜单关闭**：呼出后，再次按下“菜单键”（键盘 `Escape`，手柄 `Start 键`）或“返回键”（键盘 `Backspace`，手柄 `B 键`）即可关闭并恢复游戏。
    * **UI 选择**：键盘 `W / S` 或 `上下方向键`，手柄 `左摇杆 / D-Pad 的上下`。
    * **UI 确认**：键盘 `Space` / `Enter`，手柄 `A 键 / Cross 键`。确认后，会将模式保存到本地 PlayerPrefs 并调用黑屏渐变加载对应的 `GameONLINE` 或 `GameOFFLINE` 场景。

---

## 2. 语言选择状态 (LanguageSelect)
* **目的**：选择游戏语言（中文/英文）。
* **可用操作**：
  * **方向键（左右）**：键盘 `A` / `D` 或 `Left / Right 方向键`，手柄`左摇杆的左右` 或 `D-Pad (十字键) 的左右`。
  * **确认键**：键盘 `Space` (空格) / `Enter` (回车)，手柄 `A 键 / Cross 键`。
  * **作用**：左右方向键用于在 `CN`（中文）与 `EN`（英文）按钮之间切换选择。按确认键会触发当前选中的语言按钮，记录语言类型并自动跳转至【规则阅读】。
  * **防穿透延迟**：为了防止开始游戏时的多重按键穿透，进入此状态的前 **0.2秒内** 所有按键和点击将被忽略。

---

## 3. 规则阅读状态 (RuleRead)
* **目的**：阅读游戏规则。
* **可用操作**：
  * **确认键**：键盘 `Space` (空格) / `Enter` (回车)，手柄 `A 键 / Cross 键`。
  * **作用**：按下确认键表示已阅读，游戏跳转至【倒计时开始】。

---

## 4. 倒计时开始状态 (CountdownStart)
* **目的**：3、2、1、GO! 游戏开始前的准备阶段。
* **可用操作**：
  * **无**：此状态为纯 UI 动效播放阶段（放大 + 渐隐），玩家操作处于屏蔽状态。

---

## 5. 游戏中状态 (Gameplay)
* **目的**：控制角色移动、进行攻击、争取最高分。
* **可用操作**：
  * **角色移动**：键盘 `W / A / S / D` 或 `方向键`，手柄 `左摇杆`。
  * **角色攻击（仅播放动画）**：键盘 `Space` (空格)，鼠标 `左键`，手柄 `A 键 / X 键 / RT 触发器 / RB 肩键`。注：由于本游戏实际击杀敌人方块的机制为**碰撞接触击杀**，攻击动作仅在视觉上起表现作用，不产生实际的判定伤害。
  * **暂停游戏**：键盘 `Escape` (Esc)，手柄 `Start 键`（三横线菜单键）。
* **游戏分数实时回显**：
  * 游戏进行中，UI 分数文本（`gameScoreTMP`）会以 0 延迟实时渲染玩家的当前得分，方便实时掌握得分状态。
* **暂停菜单内的 UI 导航操作**：
  * **UI 选择**：键盘 `W / S` 或 `上下方向键`，手柄 `左摇杆 / D-Pad 的上下`。
  * **UI 点击确认**：键盘 `Space` / `Enter`，手柄 `A 键 / Cross 键`。
  * **鼠标操作**：支持直接点击菜单按钮。
  * **中途退出机制 (QUIT)**：如果在暂停菜单点击并确认了 `QUIT`，游戏不会立即重载，而是会先关闭暂停面板并恢复正常时间缩放，将游戏切换至【游戏结束】(GameState.GameOver) 状态，展示 2 秒结算过渡动效后，再自动返回首页。
  * **焦点自动保护机制**：如果在使用手柄控制菜单中途用鼠标点击了空白处，UI焦点可能丢失。此时系统会**自动将焦点重新锁定回手柄上一次选择的按钮**上，防止手柄操作失效。

---

## 6. 游戏结束状态 (GameOver)
* **目的**：显示 "Finish!" 结束字样，并执行退场特效。
* **可用操作**：
  * **无**：此状态下播放 2 秒钟的结束特效，屏蔽所有操作。在此期间，玩家角色会通过平滑缩小并淡出（DOScale 缩放到 0，DOFade 渐隐），且页面覆盖半透明紫色滤镜并弹出 "FINISH" 提示。
* **后续流向**：
  * **正常结束（限时结束）**：2 秒结束后自动进入【游戏结束页面】（GameOverPage / Panel_5）。
  * **中途退出（暂停菜单点击 QUIT）**：2 秒结束后自动重载场景返回【首页 / 待机状态】（Idle / Panel_0）。

---

## 7. 游戏结束页面 (GameOverPage)
* **目的**：显示最终得分或统计，并自动或手动返回首页。
* **可用操作**：
  * **取消键 / 返回键**：键盘 `Escape` (Esc) / `Backspace` (退格键)，手柄 `B 键 / Circle 键 (buttonEast)`。
  * **作用**：按下取消键将直接忽略倒计时，立即重载场景返回首页。如果不操作，系统在倒计时（默认 10 秒）归零后也会自动回到首页。
  * **结算打榜榜单高亮**：系统在加载结束页面后，会从 WebSocket 获取结算排行榜。如果玩家上榜，该行的名次、名字、得分将自动以**高亮黄色 (`#E1FA00`)** 显示，方便进行成绩对照。
  * **注意**：在此页面中，**确认键已被故意禁用**，无法用于触发重载。
