# 📝 更新记录: 游戏会话服务器端初始化 POST 接口对接 (2026-07-03 10:57:31)

本次更新实现了在客户端成功连接网络时，向服务器端发送 POST 请求初始化每局游戏会话的功能。

---

## 1. 核心更新与逻辑实现

### 🚀 1. 新增 `YandexGameSessionInitializer` 脚本
* **独立逻辑管理**：创建了 `YandexGameSessionInitializer.cs` 脚本，用于统一处理与服务器端会话初始化相关的网络请求。
* **单例与跨场景持久化**：采用 MonoBehaviour 单例模式并挂载 `DontDestroyOnLoad`，支持懒加载（Lazy Initialization），无需在每个场景中手动挂载。
* **动态 MachineID 获取**：
  * 优先尝试从 `YandexWebSocketClient.Instance.MachineId` 动态获取当前机器标识。
  * 备用方案：如果 WebSocket 客户端未就绪，则读取 `StreamingAssets/config.json` 中的 `machineId`。
  * 保底方案：若以上均不可用，默认使用 `"machine-1"`。
* **POST 请求规范**：
  * 请求地址：`POST https://yandexa.bbtech.cc/api/machine/reset`
  * 请求体格式：`{ "machineId": "machine-1" }`
  * 支持超时机制（5秒超时），并对请求结果进行成功/失败日志打印，确保每局初始化状态可追溯。

### 🔄 2. 精准触发初始化时机
* **网络就绪切入点**：在 `YandexLeaderboardManager.cs` 的网络状态观测器 `ConnectionObserverRoutine` 中，定位到真正输出 `[Leaderboard] Network state detected as Connected. Fetching immediately!` 的时机（即 `!wasConnected` 转为 `true` 的瞬间），触发 `YandexGameSessionInitializer.Instance.InitializeSession()` 调用，从而在每次真正连接成功时重置游戏会话。
