# 📝 更新记录: 场景切换页面呼出限制解除、按键次数调整及暂停激活 (2026-07-03 11:03:57)

本次更新移除了在非待机状态下呼出场景切换页面的限制，调整了触发按键的连续点击次数，并支持了呼出界面时的游戏暂停与关闭界面后的状态恢复。

---

## 1. 核心更新与逻辑实现

### 🌐 1. 解除呼出状态限制
* **任意阶段可用**：移除了先前在 `OnMenuPressed()` 中强制要求 `GameFlowController.Instance.CurrentState == GameState.Idle` 的限制。现在无论游戏处于什么状态（游戏中、语言选择、倒计时等），均可通过连续按 Menu 键呼出模式/场景切换界面。

### 🔘 2. 连续点击次数从 3 次调整为 5 次
* **触发条件提升**：为了防止在游戏进行中误触呼出界面，将触发界面的连续点击次数从原先的 **3 次** 提高至 **5 次**。
* 连续点击判定逻辑依然为单次按键间隔不超过 `1.0f` 秒，在限制时间内连续敲击 5 次即可成功呼出切换界面。

### ⏸️ 3. 游戏暂停与状态恢复
* **呼出暂停**：在打开场景切换界面时，记录当前 `Time.timeScale` 并将其设置为 `0f`（暂停物理更新、游戏计时器及常规帧动画），确保在游戏过程中呼出选单时游戏能够正确暂停。
* **关闭恢复**：在关闭场景切换界面时，将 `Time.timeScale` 恢复为打开前的原值，避免意外打断其他暂停状态（如网络错误重连时的暂停）。
