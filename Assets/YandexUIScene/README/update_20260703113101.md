# 📝 更新记录: 排行榜刷新频率公共化与调试日志增强 (2026-07-03 11:31:01)

本次更新将 `YandexLeaderboardManager` 排行榜的数据刷新频率参数参数公共化，并增强了拉取和解析排行榜数据的调试日志打印。

---

## 1. 核心更新与逻辑实现

### ⏳ 1. 排行榜刷新间隔公共化
* **新增参数**：在 `YandexLeaderboardManager.cs` 中增加公共属性/序列化字段：
  ```csharp
  [Tooltip("Interval in seconds between leaderboard refreshes.")]
  public float fetchInterval = 2.0f;
  ```
* **替换硬编码**：将先前 `FetchLeaderboardRoutine` 协程内硬编码的 `yield return new WaitForSecondsRealtime(2f);` 替换为自定义的 `fetchInterval` 变量，便于在 Inspector 中调整刷新频率或动态修改。

### 🔍 2. 深度排行榜数据调试日志
* **原始数据日志**：当排行榜 API 请求成功后，如果开启了 `enableDebugLogs`，会输出服务器返回的 raw JSON 串：
  ```
  [Leaderboard] Fetched raw leaderboard data: { ... }
  ```
* **解析后实体日志**：在 JSON 解析成功后，会详细遍历输出每一项排行榜条目（包括排名、姓名、电话脱敏信息、分数、结束时间），便于直接从控制台观察排序及数据状态：
  ```
  [Leaderboard] Parsed 10 entries successfully.
  [Leaderboard Entry #1] Name: xxx, Phone: yyy, Score: zzz, FinishedTime: ...
  ```
* **异常返回日志**：如果返回的数据 code 不等于 200，或者返回的 JSON 结构与序列化不匹配，会输出 `Debug.LogWarning` 警告。
